## 2. Alberta AIT Welder — Program shape

- **3 periods.** Each period = 8 weeks classroom (240 hrs) + 1560 hrs on-the-job.
- **Total to Red Seal:** ~4,680 OTJ hours + 720 classroom hours + 3 period exams + interprovincial (Red Seal) exam.
- **Period exam pass mark:** 70%
- **Red Seal pass mark:** 70%
- **Entrance minimums:** English 10-2, Math 10-3 (or GED, or AIT entrance exam).

## 6. Red Seal Exam — Blueprint (national, post-Period 3)

**Format:** 125 multiple-choice questions · 4 hours · 70% to pass
**Question type mix:**
- Knowledge & Recall: 40–50%
- Procedural & Application: 35–45%
- Critical Thinking: 10–20%

### Task weighting (this is what our mock exams must mirror exactly)

**Block A — Common Occupational Skills (16% · 20 questions)**
- A-1 Maintains tools & equipment · 4 Q
- A-2 Uses access & material handling equipment · 3 Q
- A-3 Performs safety-related activities · 4 Q
- A-4 Organizes work · 3 Q
- A-5 Performs routine trade activities · 6 Q
- A-6 Uses communication & mentoring · 0 Q (not tested, but in the standard)

**Block B — Layout & Fabrication (22% · 28 questions)**
- B-7 Performs layout · 12 Q
- B-8 Fabricates components · 16 Q

**Block C — Cutting & Gouging (18% · 23 questions)**
- C-9 Non-thermal cutting/grinding · 6 Q
- C-10 Oxy-fuel gas cutting (OFC) · 7 Q
- C-11 Plasma arc cutting (PAC) · 6 Q
- C-12 Air carbon arc cutting (CAC-A) · 4 Q

**Block D — Welding Processes (44% · 54 questions)**
- D-13 SMAW · 18 Q
- D-14 FCAW/MCAW/GMAW · 18 Q
- D-15 GTAW · 13 Q
- D-16 SAW · 5 Q

**Total: 125 questions.**

Our Red Seal mock exam will match this task-by-task. Every question tagged with its MWA/Task/sub-task so students see where their gaps are.

## 7. App feature list (v1 — iOS-first, free)

### Learning modules
- **Structure:** Period → Section → Lesson → Quiz
- **~50–70 lessons per period** (each Section broken into 3–8 lessons, mirroring AIT topic granularity)
- **Every lesson has:**
  - Learning objective (verbatim from AIT curriculum guide)
  - Plain-language explanation (apprentice-friendly, not textbook-dense)
  - Diagrams (SMAW arc, GTAW torch anatomy, joint types, weld positions, etc.)
  - Key formulas where relevant (heat input, travel speed, amperage/electrode diameter ratios)
  - Code references where relevant (CSA W47.1, W59, B51)
  - "Common exam trap" callouts
- **End-of-lesson quiz:** 5–10 MCQ, immediate feedback with explanation

### Quizzes & mock exams
- **Section quiz:** ~15–20 Q, weighted per lesson coverage
- **Period practice exam:** ~50–75 Q, weighted per AIT section hours (matches what AIT tests)
- **Red Seal full mock exam:** 125 Q, weighted per Red Seal task matrix (matches real exam blueprint exactly)
- **Timed mode** for period + Red Seal mocks
- **Review mode:** see every wrong answer with source lesson link

### Progress
- Local progress tracking (Core Data on iOS)
- Per-section mastery indicator
- Weak-area recommendations ("You're at 52% on Cutting & Gouging — review these lessons")
- Study streaks

### Offline
- All content bundled with app on install (no server needed for v1)
- Optional: fetch updated question banks over network

### Free-only for v1
- No auth, no accounts, no payments
- Everything runs on-device
- Analytics: privacy-respecting, opt-in only (Apple's AppAnalytics)

## 8. Tech stack

- **App:** Native iOS in **Swift + SwiftUI** (iOS 17+)
  - *Why not Expo/React Native?* You asked iOS-only for v1. Native is faster to ship well, smaller binary, better App Store review outcomes, better long-term maintenance. If we add Android in v2, we lift the content layer (JSON) and rebuild the shell — content stays.
- **Content format:** JSON files bundled in-app (`period1/section1/lesson1.json`, etc.)
- **Content authoring:** Markdown-first in this repo; a build step converts to JSON before app compile
- **Quiz engine:** SwiftUI state machine + deterministic scoring
- **No backend for v1**
- **Version control:** GitHub (public or private, your call)
- **Distribution:** Apple Developer account required ($99/yr — this is the only cost). App Store submission ~1–3 weeks for first review.

## 9. Content strategy (the honest hallucination-risk answer)

**Every technical claim in the app will be traceable to one of:**
1. AIT Welder Curriculum Guide (learning outcomes/objectives verbatim)
2. Red Seal Occupational Standard (task performance criteria verbatim)
3. Cited public references: CWB Group learning materials, CSA W47.1/W59/B51 references, Miller/Lincoln/ESAB manufacturer manuals (all public)

**Every quiz answer will have an explanation citing its source.** No unsourced "trust me the answer is B."

**What I will NOT do:**
- Invent Red Seal exam questions and claim they're real (that's fraud; they're confidential)
- Publish specific amperage/gas-flow recipes without citing the manufacturer or code
- Skip the SME review question (see next)

**SME reviewer path — DECIDED 2026-09-04: Path C (citations-only, no SME on day one).**

**Content rules (hard):**
1. Every technical claim in the app MUST have an inline citation the student can tap.
2. Allowed sources ONLY:
   - AIT Welder Curriculum Guide 012 (2026)
   - Red Seal Occupational Standard for Welder (2024)
   - CWB Group learning materials (public)
   - Modern Welding textbook (Bowditch, latest edition)
   - CSA W47.1 (Certification of Companies for Fusion Welding of Steel)
   - CSA W59 (Welded Steel Construction)
   - CSA B51 (Boiler, Pressure Vessel & Pressure Piping Code)
   - Manufacturer manuals: Miller, Lincoln Electric, ESAB (public product docs)
   - TWI Global public knowledge base (twi-global.com)
   - AWS (American Welding Society) public documents
3. If I cannot cite it from the above list, it does not ship.
4. Every quiz answer explanation also cites its source.
5. In-app "Report this content" button on every lesson and quiz question — users become secondary reviewers.
6. v2: paid SME (journeyman + NAIT instructor ideal) does a full pass before v2 ships.
